# Aspia+ 2.7.2 — предварительный выпуск для Windows (preview.25)

**Неофициальная модификация Aspia 2.7.0.** Тестовая сборка, не официальный релиз авторов Aspia. Лицензия GPL-3.0, соответствующие исходники и контрольные суммы приложены.

### Основные улучшения

- **Журнал удалённых подключений.** Новый Host подтверждает сеансы на Router. В Console: *Управление маршрутизатором → Журнал сеансов*. Логины Router и Host, Host ID, компьютер, тип подключения, начало/окончание/продолжительность, состояние, фильтры и CSV. Для надёжной персональной атрибуции нужны индивидуальные логины Router.
- **Автоматическая инвентаризация компьютеров.** Обновлённые Host отправляют аппаратные сведения при регистрации и примерно раз в сутки. Router их хранит; Console формирует отчёт по всей адресной книге с CPU, RAM, SSD/HDD, дисками, ОС, последней активностью; экспорт HTML/CSV.
- **Копирование файлов и папок через буфер Windows.** Ctrl+C/Ctrl+V между локальным и удалённым Проводником **в обе стороны**, без отдельного окна передачи. Требуются новые Host и Client/Console, разрешённый буфер обмена и право передачи файлов. Копирование файлов и папок в обе стороны проверялось на реальных тестовых Windows-машинах.
- **Форматированный буфер.** Согласуемая поддержка RTF, полного HTML и PNG/DIB с обратной совместимостью с обычным текстом Aspia 2.7.
- **Существующие Router/Relay и адресные книги.** Сохранён транспорт версии 2.7; Relay не менялся. Новый Router добавляет отдельные БД журнала и инвентаризации.

### Что входит в загрузку

Восемь MSI: Host, Client, Console и Router, **x86 и x86_64**; исходный код той же сборки, SHA-256, лицензия, инструкция и подготовленный статический комплект страницы загрузок для Caddy.

### Важно перед установкой

1. **Это prerelease, не стабильная массовая сборка.** Пройдены автоматические Windows x86/x64, MSI, протокольные, тесты обновления Host и сохранения пользователей/конфигурации Router. Часть длительных и межкомпьютерных сценариев всё ещё требует ручной приёмки.
2. На 1–2 тестовых компьютерах сохранить конфигурацию Host, базу и ключи Router, а затем обновлять компоненты согласованно. Старые Client/Console могут отклонять более новую версию Host/Router. Для Host сохранять **архитектуру установленного MSI**.
3. Для файлового буфера проверять большой файл, папку, отмену и повторную вставку. Переносятся данные и структура папок, но не ACL/ADS/временные метки. **Ctrl+X и drag-and-drop не заявлены.** Отзывчивость Проводника при копировании крупных папок требует дополнительной проверки.
4. Для RTF/HTML/изображений проверить нужные приложения; сложное форматирование документов Word/Excel не гарантируется.
5. Этот релиз **не меняет автоматически** сервер обновлений, сайт загрузок и работающие Router/Relay.
